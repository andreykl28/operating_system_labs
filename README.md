# Лабораторные работы по курсу «Операционные системы»

Данный репозиторий содержит выполнение лабораторных работ по дисциплине «Операционные системы».

## Структура репозитория

Каждая лабораторная работа организована в виде отдельной директории и содержит исходный код программы, правила автоматической сборки и отчет о выполнении.

- **[lab2/](./lab2/)** — Лабораторная работа №2: «Управление процессами и межпроцессное взаимодействие (pipes)»
  - `src/` — исходные коды программ (`parent.c`, `child.c`, `utils.c`, `utils.h`) на языке Си (C11 / POSIX API).
  - `report/` — отчет по лабораторной работе (`report.md`) и файлы трассировки системных вызовов (`strace.txt`, `strace_short.txt`).
  - `Makefile` — сценарий сборки со строгими флагами компиляции (`-Wall -Wextra -Werror -std=c11 -pedantic`).

## Сборка и запуск

Для сборки проекта перейдите в каталог лабораторной работы и вызовите `make`:

```bash
cd lab2
make
```

Запуск родительского процесса:

```bash
./parent
```
