# Отчет по лабораторной работе №2
## «Управление процессами и межпроцессное взаимодействие (pipes)»
**Дисциплина:** Операционные системы  

---

## 1. Цель работы
Приобретение практических навыков:
- Управления процессами в ОС Linux (`fork`, `execve`, `waitpid`);
- Организации межпроцессного взаимодействия с использованием однонаправленных неименованных каналов (`pipe`);
- Перенаправления стандартных потоков ввода/вывода (`dup2`);
- Профилирования и диагностики системных вызовов (`strace`).

---

## 2. Задание (Группа вариантов 5, Вариант 21)
1. Родительский процесс (`parent`) создает два дочерних процесса (`child1` и `child2`), запускающих один и тот же исполняемый файл `./child`.
2. Пользователь первой строкой вводит имя первого файла (для `child1`), второй строкой — имя второго файла (для `child2`).
3. Родительский процесс открывает оба файла на запись с флагами `O_WRONLY | O_CREAT | O_TRUNC` и правами `0644`.
4. Создаются два неименованных канала: `pipe1` и `pipe2`.
5. Потоки ввода/вывода дочерних процессов перенаправляются с помощью `dup2`:
   - `child1`: `STDIN` перенаправлен на чтение из `pipe1`, `STDOUT` — в дескриптор первого файла.
   - `child2`: `STDIN` перенаправлен на чтение из `pipe2`, `STDOUT` — в дескриптор второго файла.
   - После перенаправления вызывается `execl("./child", "child", NULL)`.
6. Родительский процесс в цикле читает строки произвольной длины от пользователя:
   - Нечетные по счету строки (1, 3, 5...) отправляются в `pipe1`.
   - Четные по счету строки (2, 4, 6...) отправляются в `pipe2`.
7. Дочерние процессы читают строки из своего `STDIN`, инвертируют порядок символов в каждой строке (сохраняя `\n` на конце) и записывают результат в свой `STDOUT`.
8. При завершении ввода (EOF / `Ctrl+D`) родитель закрывает записывающие концы каналов, дожидается завершения обоих детей через `waitpid` и корректно освобождает все ресурсы.


### 3.2. Схема взаимодействия процессов
```text
           [ Пользователь / stdin ]
                      │
                 [ parent ]
               ┌──────┴──────┐
       (нечетные)         (четные)
               │             │
           [ pipe1 ]     [ pipe2 ]
               │             │
           [ child1 ]    [ child2 ]
               │             │
          (инверсия)    (инверсия)
               │             │
          [ файл 1 ]    [ файл 2 ]
```

### 3.3. Реализация динамического ввода строк
В соответствии с требованиями работа с потоками ввода-вывода выполнена исключительно через низкоуровневые системные вызовы POSIX (`read`, `write`, `open`, `close`, `dup2`, `pipe`, `fork`, `execl`, `waitpid`). Высокоуровневые функции `<stdio.h>` (`printf`, `scanf`, `fgets`, `getline`) не используются.

Чтение строк произвольной длины реализовано в функции `read_line(int fd, char **out)`:
- Память выделяется динамически порциями (стратегия удвоения буфера через `malloc` / `realloc`);
- Чтение осуществляется побайтово через `read()`;
- Обрабатывается ситуация `EINTR` (прерывание системного вызова сигналом);
- Буфер не ограничен фиксированным размером `PATH_MAX` или 4096 байтами.

## 4. Сборка и запуск

Сборка осуществляется с помощью утилиты `make`:
```bash
make
```

Запуск программы:
```bash
./parent
```

Пример входных данных:
```text
out1.txt
out2.txt
Hello World
Foo Bar
Abcdef
Test
```

Результат:
- `out1.txt` (нечетные строки 1 и 3, инвертированные):
  ```text
  dlroW olleH
  fedcbA
  ```
- `out2.txt` (четные строки 2 и 4, инвертированные):
  ```text
  raB ooF
  tseT
  ```

## 5. Профилирование системных вызовов (`strace`)

Для сквозной диагностики системных вызовов программа была запущена под управлением утилиты `strace` с флагом `-f` (отслеживание порожденных процессов):
```bash
printf 'out1.txt\nout2.txt\nHello World\nFoo Bar\nAbcdef\nTest\n' | strace -f -o report/strace.txt ./parent
```

### Таблица ключевых системных вызовов программы

| Системный вызов | Назначение в программе |
|---|---|
| `openat` | Создание и открытие целевых файлов `out1.txt` и `out2.txt` на запись (`O_WRONLY \| O_CREAT \| O_TRUNC`) |
| `pipe2` | Создание неименованных каналов `pipe1` и `pipe2` для передачи данных |
| `clone` | Создание дочерних процессов `child1` и `child2` (низкоуровневая реализация `fork()`) |
| `dup2` | Перенаправление `STDIN_FILENO` в канал чтения и `STDOUT_FILENO` в файл |
| `execve` | Замена образа дочернего процесса на бинарник `./child` |
| `read` | Побайтовое динамическое чтение строк из терминала и из каналов |
| `write` | Запись строк в каналы (родителем) и запись инвертированных строк в файлы (детьми) |
| `close` | Своевременное закрытие неиспользуемых концов каналов и файловых дескрипторов |
| `wait4` | Ожидание завершения дочерних процессов родителем (низкоуровневая реализация `waitpid()`) |

Выжимка системных вызовов без библиотечного шума сохранена в файле `report/strace_short.txt`.
